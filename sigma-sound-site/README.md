# Сайт Sigma Sound

Статический сайт без сборки: открывается двойным кликом по `index.html` и публикуется на любом хостинге (Cloudflare Pages, Netlify, GitHub Pages).

| Файл | Страница |
|---|---|
| `index.html` | Главная: три направления, процесс, бренды, форма |
| `home.html` | Оборудование для дома |
| `venues.html` | Бары, рестораны, клубы |
| `security.html` | Камеры и безопасность |
| `style.css` | Общие стили |
| `site.js` | Шапка, футер, форма, переключатель RU / עב, анимация эквалайзера |

## Перед запуском заменить
В начале `site.js`, блок `CONFIG`:
- `whatsapp`: номер в формате `9725XXXXXXXX`; форма собирает заявку и открывает WhatsApp с готовым текстом;
- `phoneShown`, `email`, `instagram`: контакты, которые видны на сайте;
- `area`: район работы.

Почта пока не указана (`email: ""`); когда появится, впиши её, и она покажется в блоке контактов.

## Тексты
Каждая фраза написана дважды: `<span data-l="ru">…</span><span data-l="he">…</span>`.
Язык по умолчанию русский, выбор посетителя запоминается в браузере.
Иврит стоит показать носителю языка перед запуском.
